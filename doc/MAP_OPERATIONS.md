# 広域マップ・Unit操作・詳細ビュー

更新日: 2026-10-17。開始基準: main / 18f7dab4fcb77863ad9609861c1d139bb3d95dec。

## 新規開始と既存セーブ

新規マップは半径10・331セルです。首都に戦士1体を含む部隊1があり、選択済みで開始します。最初の戦士はセットアップで配置し、Goldを消費しません。初期画面の軍事力は12です。

既存セーブは地形・範囲・Unit・Partyをそのまま読み込みます。37セルのセーブを自動拡張したり、戦士を追加したりしません。331セルで遊ぶ場合は新規開始を使います。カメラ位置とUI選択はゲーム状態へ保存しません。

## 地図を見る

地図はドラッグ、または地図へフォーカスして矢印キーで移動できます。＋/−とホイールで100%・200%・300%を切り替えます。地形とUnit画像は等方整数倍率を維持し、狭い画面へ無理に押し縮めません。

右下の全体図には現在の表示範囲を白枠、Unit位置を白点で表示します。全体図をクリックするとその場所へカメラが移ります。「首都へ」「選択Unitへ」「次の部隊」で対象を見失わずに戻れます。

左クリックはセル・駒の詳細確認です。選択だけでGoldや移動力を消費しません。解除ボタン・Escで部隊とUnitの選択を解除し、セル詳細はそのまま確認できます。

## Unitを選んで動かす

初期部隊や編成済み部隊は、地図の戦士の駒か右側の一覧から選択します。現在の移動力で届くセルが点線で表示されます。目的地を選ぶと経路と消費移動力が表示され、「ここへ移動」で確定します。目的地の右クリックでも同じ移動を実行できます。

移動力が残っていれば2セル以上の経路も選べます。経路探索は地形コストを考慮し、Void・他部隊の占有・行動終了・敗北・戦闘可能構成員なしを拒否します。次ターン以降へ続く自動移動予約ではありません。移動力を使い切ったらターンを終了します。

生産・購入直後の未編成Unitは、都市上に「待」と人数を付けて表示します。地図の待機駒、部隊・待機一覧、セル詳細の駐留一覧から選択できます。待機Unitを動かすには部隊へ編成します。

セル詳細で1〜5体をチェックし「選択した○体で部隊を作成」を押すと、その構成員だけで部隊を作ります。「待機Unitを最大5体選択」も使えます。Unit詳細の「このUnitで部隊を作成」は1体だけで作る操作です。既存部隊が同じセルを占有している場合は、先にその部隊を移動してください。既存部隊への加入・分割・合流は今回追加していません。

3×3配置はこれまでどおり、Unitを選択して空き枠へ移動、または2体を交換します。配置を選択したUnitの個別内容も詳細欄へ表示します。

## セル・Unitの内容

セル詳細は地形、cube座標、所有者、都市、地形の基本産出、進入コスト、駐留部隊と全Unitを表示します。基本産出は地形の値で、都市中心・建物の加算を含む都市全体の産出とは別です。領土購入は価格を表示した明示ボタンで行います。部隊選択中でも購入できます。

Unit詳細はHP、状態、所属国・部隊、位置、3×3配置、指揮者、近接・遠隔、防御・装甲、射程、所属部隊の移動力・攻撃回数を表示します。未実装のGuardや能力実行を、利用可能な操作として表示しません。
