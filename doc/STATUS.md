## 4. 優先度の高い不具合

### P0: 主要ループを止める問題

1. player.resources.金 と player.resources.gold の不一致により領土拡張できません。
2. production の初期値と産出がともに0で、ユニットと建物を作れません。
3. CharacterLayer.addCharacter が存在せず、条件を満たしてユニット作成に成功すると例外になります。
4. キャラクターの player が数値ID、文字列、undefined の混在で、自軍ユニット判定が成立しません。
5. CharacterLayer.characters と Player.units が別管理で、作成、表示、移動、ターン状態が同期しません。
6. 現行 endPlayerPhase は全員を手動プレイヤーフェーズとして扱い、OTHER_PLAYERS_PHASE と CPU_PHASE を迂回します。

### P1: 結果の正しさを損なう問題

1. キューブ座標を q、r、s それぞれ単純に丸めており、クリック位置によって q + r + s = 0 を正しく保てない可能性があります。標準的な cube round が必要です。
2. 経路に開始地点が含まれ、移動処理が開始地点の地形コストを消費します。
3. 移動時のコスト計算が毎回 unit.hex を基準にし、複数歩経路の辺判定が正しくありません。
4. 川と壁をローカル変数 hex に保存した直後に捨てています。
5. 敵と蛮族はマップ外や Void に移動できます。
6. 初期領土が重複可能で、Player.territory と Tile.owner が矛盾します。
7. resourcesJSON の value は初期資源へ反映されません。
8. Forest が生む wood は資源マスターに存在せず、UIにも表示されません。
9. Plain の色分岐がなく灰色表示になります。

### P2: 保守性と表示上の問題

1. TileLayer.draw のたびに地形名テキストを追加し、古いテキストを破棄しません。
2. BuildingLayer.draw も既存テキストを追跡、破棄しないため再描画で重複します。
3. カメラズームに上下限がありません。
4. 右クリックの既定メニューを抑止していません。
5. UIがワールド座標上にあり、カメラ移動とズームの影響を受けます。
6. currentPlayer という未設定プロパティを初回表示に使っています。直後に更新されるため目立ちにくい問題です。
7. hasActed と hasProduced を定義しないまま isPlayerActionComplete が参照します。
8. GameScene 内に未使用の重複メソッドと大量の旧コメントコードがあります。
9. SceneManager、EventManager、GUIManager は定義されますが使われません。
10. テスト、Lint、フォーマット、エラー表示がありません。
