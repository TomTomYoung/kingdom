# 地図中心の操作画面

更新日: 2026-11-04。PR #15。ゲームの数値・保存形式・手番規則は変更せず、画面の配置と操作への入口を変更しました。[手番規則](TURN_FLOW.md)と併せて参照してください。

## 常時表示

- 上端: 資源、ターン、現在の手番、都市・部隊・研究・履歴・操作ガイド・メニューへの入口。
- 中央: 画面の残りの高さを使う地図。拡大縮小・都市へ・Unitへ・次の部隊、操作結果、全体図を重ねて表示します。
- 下端: 選択中の都市・部隊・待機Unitの概要と、その対象の操作。都市なら生産・購入・都市詳細・砲撃、部隊なら移動・攻撃・能力・休養・配置・再編などへ進めます。
- 右下: 未処理件数と一覧、次に指示する対象、「次の行動」と個別の「スキップ」。未処理が0件になると「ターンを終了」に切り替わります。他プレイヤー・NPCの行動中と対局結果もここへ表示します。

ページ全体はスクロールしません。狭い画面の資源列・操作列は横方向へ送れます。文字を小さくするだけで全機能を詰め込む構成にはしていません。

## 詳細を開く

管理メニュー、下端の操作、または未処理行動から、一つの詳細パネルを開きます。表示内容の選択欄から都市、生産・購入、研究、部隊一覧、Unit詳細、配置、能力、休養・離脱、部隊再編、戦闘・護衛、攻城・占領、都市砲撃、都市建設、セル詳細、行動一覧、状況・履歴、国力、メニュー、操作ガイドを切り替えます。

PCでは地図右側に重ね、スマートフォンでは地図の下側から開きます。パネルの見出し・切替・閉じるボタンは固定し、長い内容だけを内部でスクロールします。パネルは地図のレイアウト領域を消費しないため、開閉や内容切替で地図の寸法・カメラ位置・倍率は変わりません。下端の手番操作は開いている間も使えます。

×またはEscで閉じ、開いたボタンへフォーカスを戻します。詳細を閉じた状態でEscを押すと、従来どおり部隊・Unitの選択を解除します。詳細表示に適した対象がない場合は、対象選択の案内を表示します。メニューに新規ゲーム・セーブ・ロード・音声設定、履歴に対局状況・AIの行動・AI停止時の再開を置きます。

## 手番の操作

「次の行動」は部隊を選択するか、生産・研究・砲撃などの詳細を開きます。自動中央寄せは行いません。地図上の場所を見たい場合は「Unitへ」「都市へ」を明示的に押します。

「スキップ」は表示中の未処理対象1件だけを今の手番で保留します。全件一覧から個別スキップ・取消もできます。移動後など、まだ合法な行動が残る対象は未処理一覧に残ります。手番の条件と精算順序はPR #14の規則を継続します。

## 実装の境界

`src/ui/hud-shell.js`は詳細の開閉・切替・フォーカス復帰を担当します。GameState、Command、カメラには依存しません。`main.js`は現在の選択と合法な行動から下端を更新します。各機能パネルのコールバックは従来のCommand／RuleSystemを使い、表示切替そのものはゲーム状態や乱数を変更しません。`hud.css`が画面の枠とブレークポイント、既存`style.css`が各機能の内容を担当します。

## 検証

`tools/qa/browser-hud.mjs`は自動ナビゲーション補助を使わず、実際のボタンと選択欄で操作します。1440×900、1366×768、390×844、844×390で文書のはみ出し、地図・フッターの位置、詳細の内部スクロール、開閉時の地図寸法・カメラ不変を検証します。全詳細への到達とGameState不変、Escフォーカス復帰、対象別操作、未処理からの生産・研究選択、個別スキップ・取消、終了精算、保存・ロード、実戦闘、携帯画面の終了操作、AI手番を含みます。

既存機能スイートは`hud-navigation.mjs`で公開メニューから対象パネルを開いてから同じ検証を行います。非表示属性の書換え、ゲーム状態の注入、無効ボタンの強制有効化は行いません。最終結果は[進捗記録](STATUS.md)に記載します。
