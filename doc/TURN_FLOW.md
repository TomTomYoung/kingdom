# 手番の未処理行動とターン終了精算

画面の配置と操作への入口は[地図中心の画面構成](UI_LAYOUT.md)を参照してください。

更新: 2026-11-04。PR #13後のmain 96b2100を基準に、ユーザー指定に従い手番を変更しました。

## 操作

全8モードの新規開始と画面からの旧保存ロードに適用します。「このターンの行動」へ、その時点で合法な操作のある部隊、編成可能な待機Unit、生産未選択の各都市、未選択の研究、砲撃可能な各都市を表示します。移動、近接・遠隔攻撃、攻城、占領、都市建設、能力、休養、離脱、補充・合流・分割の候補は既存の検証関数から取得します。対象や経路の全組合せを別々の義務にはせず、一部隊への指示としてまとめます。

候補ボタンまたは「次の行動」で対応する操作欄を開きます。実行で候補を再計算し、移動後も行動可能なら部隊を一覧に残します。攻撃などで行動が終了した部隊、合法な操作がない部隊、敗北部隊は終了を妨げません。購入・領土取得・生産予約の編集・配置・護衛設定は各詳細から随時行う管理操作です。

各項目を「この項目をスキップ」でその手番だけ保留できます。スキップは移動力、反応、チャージ、資源を消費せず、休養や防御の効果も与えません。取消、または該当する対象への実操作で未処理に戻ります。未処理0件になると「ターンを終了」が有効になります。次の手番・次ターンへスキップを引き継ぎません。

移動完了・AIの移動・手番交代では地図カメラを動かしません。ドラッグ、矢印キー、全体図、倍率変更、明示的な対象選択や「Unitへ」「都市へ」は引き続き利用できます。未処理行動への誘導は操作欄を開くだけでカメラを中央寄せしません。

## 一巡の順序

1. 自分の手番で未処理行動を実行または個別にスキップします。
2. EndTurnが未処理0件を検証して、turnOrderの次の参加者へ渡します。交互操作では次の人間が操作し、AI/NPC王国は既存AIが行動します。
3. 最後の参加者が終了すると、一巡分の休養、人心の維持費と収入、都市産出、食料・成長、都市防御修復、生産、国庫・科学・文化、文化拡張、研究を一度だけ精算します。
4. 次ターンの移動・攻撃・反応・Guard容量・砲撃と能力のターン使用回数を回復します。有限チャージは補充しません。

新規開始の第1ターンには収入を先払いしません。初期国庫はGold100、mana0、人心30、科学・文化0、食料0です。生産対象を選べば第1ターン終了の精算から生産します。途中の人間→AIなどの交代では精算・行動値回復を行いません。勝敗が確定した場合は直ちに終了し、終了後の収入やAI命令は発生しません。

ブラウザのAIは1 Commandずつ進め、AI手番中も確認・保存が可能です。AIが任意の判断を終えた後は、残った項目にSkipTurnActionを発行してからEndTurnします。AI命令数制限に達してもEndTurnの強制迂回はしません。既存AI王国以外の蛮族等の独立NPCは今回追加していません。

## 状態・API・保存

- `turnFlowVersion: 1`。
- `turnTasks: { turn, playerId, skipped: string[] }`。対象IDは`party:`、`unit:`、`production:`、`bombardment:`、`research:`。
- `lastSettledTurn`は最後の精算済みターン。安定した保存では`currentTurn - 1`。
- `listTurnTasks(state, playerId)`は純粋な合法候補列挙。`pendingTurnTasks`はスキップ済みを除きます。乱数・ID・ゲーム状態を変更しません。
- `SkipTurnAction`／`ResumeTurnAction`のpayloadは`{ taskId }`。現在の手番にある対象だけを受け付け、Command重複・異なるプレイヤー・古いターンを通常のRuleSystemで拒否します。
- `EndTurn`の未処理チェックはコアにあります。ボタンのdisabledを外しても通りません。
- `processTurnEnd`は全員一巡後の経済・研究等の精算、`processTurnStart`は行動値の回復を担当します。精算イベントは終了したターン番号で記録します。

画面の新規対局は初期セットアップ後、StartTurn前に`enableTurnFlow`を適用します。ロードは`restoreGameState`で全体を検証した後、旧保存に同じ手番方式を適用します。移行時は既収入、現在HP・行動値、研究、生産、乱数、過去ログを変更しません。旧保存で既に受け取った初回収入は返還せず、次の一巡後から新しい精算境界を使います。新しいスキップ状態はロードでも保持します。

低水準の既存scenario factory／restoreは旧形式のリプレイをそのまま扱うため、版なしの状態も扱います。外部から今回の操作方式で実行する場合は、セットアップまたは復元の検証後に`enableTurnFlow`を適用します。画面から新規・ロードした全対局では常に適用済みです。

新バージョンの欠落・未知版、精算番号、現在手番との不一致、重複・不明・他国のスキップ対象をロード前に拒否します。失敗操作と不正ロードは現在の状態を維持します。

## 参考と適用範囲

[2K公式Civilization VIマニュアル](https://downloads.2kgames.com/civilization/vi/manuals/eu/CIV_VI_25TH_ONLINE_MANUAL_ENG.pdf)のTurn Structure、Unit Action List、Skip Turnを参照しました。自分の行動→各相手の手番→自分の次手番という順序と、指示待ち・個別スキップの操作を採用しています。生産・研究にもスキップを認めること、カメラを移動に追従させないこと、全員行動後にまとめて精算することは今回のユーザー指定です。Civ6の全仕様を実装した意味ではありません。
