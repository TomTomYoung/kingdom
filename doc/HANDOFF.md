## 1. 再開位置

M1都市運営と、M2の複数都市・Party・配置・移動・戦闘をCanvas 2D／DOMで操作できます。GameState、ES Modules、Command／RuleSystem、Node標準テストは導入済みです。旧Phaser版の再実装は不要です。

「遠隔部隊の二国対戦」→「新規開始」で、各国の戦士2・弓兵2・弩砲1を使えます。敵を選び、遠隔・攻撃内容・照準を指定して予測を確認します。通常・狙い射ち・精密射撃・横列・縦列・十字・貫通を共通Resolver／予測／ログで解決します。従来の戦士3体ずつの二国対戦と、通常331セル開始、旧37セル保存を維持しています。

二国対戦は交互操作のままです。「AIとの遭遇戦」は人対AIで、全敵部隊撃破による勝利・敗北と期限の引き分けまで進行できます。新兵種は「弓」「弩」バッジで識別し、専用画像・射撃SEは未制作です。

## 2. 維持する設計境界

1. GameStateを正本とし、操作はCommandとRuleSystemを通します。表示選択やカメラをGameStateへ混ぜません。
2. 地上の移動・戦闘主体はParty。最大5Unit、3×3配置を対象と被害配分へ使います。
3. 移動力、攻撃回数、反応、有限Charge、Abilityコスト、都市生産・購入を分離します。
4. 戦闘・領土のseed付きRNGは分離します。予測は次の乱数を読みません。
5. 失敗Commandは状態・RNG・資源・ID・ログを変えません。保存復元後の再現性を維持します。
6. 目標仕様と暫定実装を区別します。平均戦闘力、固定移動力2、簡略HP0、正面・公開配置は完成仕様ではありません。

## 3. 今回までに解消した課題

K-01〜K-06、K-08、K-09は修正済み。K-07は固定二国の交互操作に対応し、戦術AIを追加済みです。兵の生産・購入・増援編成も追加済みです。任意プレイヤー・拡張や3研究施設と城壁以外の建物を含む戦略AI・オンラインは残っています。

K-10はPR #4で修正しました。占有するのはactive Partyだけです。敗北Party・Unit・HP・配置・位置を履歴として保持し、地図の駒と占有から除外します。撃破地点へ移動・通過・新Party作成ができ、生存Partyと敗北記録が同じ座標にある保存も復元できます。撃破直後の自動前進・回復・捕虜・Lootは未実装です。

保存のaccuracy／evasion／tauntStrength／coverPowerを検証し、旧保存の欠落にはaccuracy 1、他0を補完します。既存のGuard率・容量0を変えません。不正なstatusEffectsの識別子で予測が例外になる問題も拒否検証と安全な参照で修正しました。

## 4. 戦闘の引き継ぎ

[RANGED_COMBAT.md](RANGED_COMBAT.md)に定義・payload・配分・予測を、[COMBAT_OPERATIONS.md](COMBAT_OPERATIONS.md)に操作を記録しています。

攻撃定義は信頼済みの表から選び、クライアント指定の倍率は受け付けません。弓兵用攻撃には届く弓兵、弩砲用攻撃には届く弩砲自身が必要です。別兵種の長射程を借りません。狙い撃ちの命中には射手accuracy、対象evasion、同列前方のCover、露出Tauntを使います。通常攻撃は命中し、Taunt優先で露出対象を選びます。

範囲の対象集合は攻撃前に固定し、主対象だけGuard／Interceptを1回解決します。同じUnitへの直撃と肩代わりは合算して装甲を1回適用します。貫通は生存対象ごとに減衰し、空き枠・HP0で深度を消費せず、他列へ流しません。配分が0なら最低1Damageを作りません。

## 5. 都市の引き継ぎと次作業

[CITY_MANAGEMENT.md](CITY_MANAGEMENT.md)にモデル・操作・移行条件を記録しました。「二都市運営」で暁都・東都を切り替えられます。都市選択は表示状態だけで、生産・購入・領土価格・候補はすべて選択都市へ揃えています。食料・生産・文化は都市別、Gold等の国庫は王国共有です。

Tile.ownerIdは王国、Tile.cityIdは中心、Tile.territoryCityIdは所属都市です。新規取得は実行都市へ固定し、所属を距離で再分配しません。作業は自都市の非Void領土から人口数まで、半径制限は今回追加していません。共通境界は先取得都市へ所属し、文化取得順はcityIds順です。

cityTerritoryVersion 1と全tile所属を保存します。完全な旧保存だけ最近同国都市・同距離ID順で移行し、複数都市の重複作業・表示集計・派生能力を直します。既収集資源やRNGは動かしません。負の補正後は産出0以上、存在する内訳は型・参照・数値を検証し、省略内訳は表示で捏造しません。

Settler／FoundCityは実装済みです。開拓者は生産30・Gold120、攻撃しない民間Unitです。FoundCityはpartyIdとsettlerUnitIdを受け取り、未所有・非Void・既存都市から4ヘクス以上・他活動中部隊/敵Unitの不在・移動力1以上・未終了を検証します。新都市は人口1で次の全体ターン開始から収入を得ます。これらの数値は今回の暫定設定です。

開拓者だけを消費し、護衛の配置・HPを保持します。空Partyは削除、残る部隊は行動終了、指揮者と護衛指示の参照を修復します。初期領土は中心と未所有・非Voidの周囲だけで、既存所属を移しません。nextIds.city欠落は旧都市の最大連番+1で補完します。拒否Commandは全状態を保持します。

AIControllerと部隊撃破のScenario Objectiveを実装済みです。[AI_SCENARIOS.md](AI_SCENARIOS.md)に判断順・終了規則・保存検証・UI再開を記録しています。AIの判断はRNGを読まず、選んだCommandはRuleSystemを通します。40ターン終了時の引き分けは次ターン収入の前に確定します。旧モードには勝敗条件を後付けしません。

兵の生産・購入と増援編成を「AIとの増援戦」に実装しました。aiPolicyを省略した旧AIは戦術のみを維持します。予備費24、都市ごとに1ターン1購入、生存兵＋予約兵15体までの新規発注、兵種比率2:2:1は暫定値です。生産対象・キューが空の都市だけ生産設定し、既存進捗・キューを維持します。自軍の都市占有を合法移動で解消し、待機兵を最大5体で編成して戦闘へ送ります。

Partyの補充・合流・分割を実装しました。関係部隊は未終了・移動力1以上、合流・分割は隣接と地形費を検証し、成功時に移動・攻撃・反応を0として終了します。HP・護衛残量・配置を保持し、分割時だけ部隊をまたぐ護衛を解除します。増援AIは同じCommandで補充・合流し、自動分割はしません。詳しいpayloadと保存互換は[PARTY_MANAGEMENT.md](PARTY_MANAGEMENT.md)にあります。

都市占領と「AIとの都市争奪戦」を実装しました。CaptureCityは敵都市中心の軍事部隊・未終了・攻撃1以上を必要とし、成功すると移動・攻撃・反応を0にします。都市と所属領土を移管し、人口・建物・食料・文化・Unitを保持、生産予約・進捗を解除します。収入は次の全体ターン開始からです。全都市を失うと即敗北し、部隊全滅だけでは終了しません。新目標control-citiesだけに適用し、旧遭遇戦・増援戦はeliminate-partiesを維持します。

AIは占領を最優先し、敵都市への合法経路を選びます。中心が活動部隊に塞がれた場合は攻撃・接近を使い、地形費不足なら待ちます。兵が尽きても都市から再建できます。都市0の敗者も王国・部隊記録を保持し、画面・地図・保存復元を継続できます。仕様・残る制約は[CITY_CONQUEST.md](CITY_CONQUEST.md)を参照してください。

新規都市争奪戦に耐久100・城壁60・AttackCity・自然修復を実装しました。進入と占領は両HP0が必要で、占領後は耐久25・城壁0になります。版なし旧保存は即時占領のままです。弩砲補正・回復待機・敵軍隣接での修復停止・新都市への初期化・地図バー・予測・ログ・AI攻城を[CITY_SIEGE.md](CITY_SIEGE.md)に記録しました。

都市反撃と城壁建設AIは版2の新規対局へ追加しました。近接攻城後に防御が残る都市は全体ターン1回反撃し、Guard・Intercept・装甲・士気・指揮者・敗北を共用します。反撃中の割り込み後に攻城側の反応を0とし、都市回数は占領時0・全体ターン開始1です。AIの城壁は最低5生存兵・活動部隊・脅威3ヘクス以内を必要とし、予備費24・都市別購入上限1・既存予約を保持します。旧版1は反撃と城壁AIを追加しません。[詳細](CITY_RETALIATION.md)。

休養・回復と戦闘不能者の離脱は実装済みです。新規partyRecoveryVersion 1だけにRestParty／RemoveCasualtiesとAI判断を追加しました。回復は次の全体ターン開始にHP+20／自国都市中心+30、被害・敵接近で中止します。離脱はHP0のUnit記録を保持し、部隊参照・配置・護衛・指揮者を修復します。軍事力は生存非民間Unitだけを数えます。旧版なし保存の状態・AI継続・軍事力式は保持します。[詳細](PARTY_RECOVERY.md)。

PR #7はmainの8534535へマージ済みです。続いて都市の生産キュー編集UIを実装しました。[操作・規則・保存](PRODUCTION_QUEUE.md)を参照してください。

PR #8をmainのb136804へマージ後、新規cityDefenseVersion 3へ能動的な都市砲撃を追加しました。[都市砲撃](CITY_BOMBARDMENT.md)を参照してください。暫定で射程2・戦闘力20・都市ごとに全体ターン1回、都市耐久と城壁HPが必要です。既存の自動反撃と駐屯部隊の行動は独立しています。予測・UI・ログ・AI・保存を共通Commandへ接続し、旧版2・1・版なし保存には砲撃を追加しません。

新規researchVersion 1で王国共通の研究対象選択・一時停止・種類別進捗・前提技術・施設解禁を追加しました。科学累計は従来どおり一度だけ収集し、累計から完了費用と途中進捗を差し引いた未配分分を、全都市収集後に選択研究へ配分します。累計や軍事力式を減算しません。旧保存は新しい版・研究・AI判断を追加せず維持します。 暫定3研究・3施設、既存兵種の条件維持、都市占領で施設は維持し研究は移管しない規則を[研究仕様](RESEARCH.md)に記録しました。新規aiInfrastructureVersion 1では解禁施設への投資AIも追加しました。[投資条件](AI_INFRASTRUCTURE.md)。

次の候補は都市拡張AIです。既存FoundCityを共用し、軍隊再建を妨げない開拓者・護衛確保、合法な建設地点への移動と建設を段階実装してください。既存の距離・地形・領有・占有・移動力・護衛保持の検証を緩めず、保存再開と旧AI互換を確認します。全ての戦略判断が完成したとは扱いません。
