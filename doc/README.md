## 現状の要約

Kingdom は Phaser 3.55.2 を CDN から読み込んで動く、単一 HTML のヘックス制ストラテジー試作です。ランダム地形、3プレイヤー、領土、資源、人口、ユニット、建物、技術、イベント、ターン状態、移動経路探索の骨格があります。

ただし、現在の main は完成したゲームではありません。画面の生成とターン送り、資源収集、イベント表示の一部は動く見込みですが、領土拡張、ユニット作成、建物建設、ユニット移動にはデータ不整合または未定義メソッドがあり、主要なゲームループは成立していません。まず HANDOFF.md の P0 を解消してから機能追加へ進むのが安全です。
