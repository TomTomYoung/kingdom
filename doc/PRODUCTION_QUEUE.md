# 生産キューの編集・停止・保存

更新日: 2026-10-30。PR #7マージ後のmain / 8534535422972c04f958a437fee8df5dbf12c9efを基準に追加しました。目標仕様全体の完成ではなく、現行都市生産への操作追加です。

## 操作

「操作する都市」で選択した都市の「生産キューを編集」を押します。先頭が現在の生産対象、続く項目が予約です。末尾への追加、前へ／後への移動、各項目の削除、全件削除を編集案として操作できます。「この内容で確定」を押すまでゲーム状態は変わりません。「編集を取り消す」は案だけを破棄します。

全件削除した案ではボタンが「生産を停止して確定」に変わります。停止しても種類別の途中進捗は残ります。再び同じ種類を選ぶと続きから生産します。既存の直接生産ボタンは対象だけを切り替え、予約を保持します。予約中の建物を直接の生産対象へ昇格させた場合、その建物の予約だけを除き、二重建設を防ぎます。

建設済みの建物・同じ建物の重複予約は不可です。同種Unitは複数予約できます。城壁の利用可能条件は従来どおり、都市防御を有効にした対局です。Gold購入は独立しており、建物購入時はその建物を現在対象・予約から除き、その建物の進捗を0へ戻します。Unit購入では予約・進捗を消しません。

## 進捗と表示

進捗は注文単位ではなく、都市の対象種類ごとのprogressByItemです。同種Unitを複数並べても進捗を複製せず、その種類の最初の1件だけが既存進捗を使います。完了後は既存規則どおり0から次を生産し、超過生産は次の予約へ流れます。予約が空のときや生産停止中の産出を備蓄する仕組みは追加していません。取消時の返金・進捗移転・新しい費用もありません。

一覧は必要生産・適用される途中進捗・累積の完了目安を表示し、一覧にない種類の進捗も「保持中の進捗」として表示します。完了目安は表示中の生産量が変わらない場合の全体ターン開始回数です。人口増加、領土取得、建物完成、補正による将来の産出変化は予測しません。産出0では完了見込みなしと表示します。表示は収集処理や乱数を実行しません。

## Commandと拒否条件

確定は既存のSetCityProductionを1回実行します。通常はpayloadのcityId、itemId、queueを指定します。生産停止だけは明示的にitemId:null、queue:[]を指定します。itemId省略、不正型、nullと空でないqueueの組み合わせは拒否します。所有権・手番・フェーズ・終了状態・既処理commandId・不明ID・重複建物の検証は維持します。

拒否時は元のGameState、資源、乱数、ID、ログを変更しません。UIから状態を直接書き換えず、HumanControllerとRuleSystemを通します。確定成功後の状態・イベント・Commandログに一貫して反映します。

## 編集案の寿命と保存互換

編集案はUI専用です。セーブするのは確定済みのキューだけです。都市切替、操作プレイヤー変更、成功Commandによる状態更新、ロード、新規開始、手番終了で未確定案を破棄し、通知します。地図の確認や同一状態の再描画だけでは案を失いません。AI手番、対局終了、操作可能な所有都市なしでは編集できません。確定拒否時は修正できるよう案を保持します。

GameStateの保存形式や版フィールドは増やしていません。currentItemId:nullは既存保存形式でも有効です。旧AI、旧都市防御版、休養版なし保存に新しい版を付けません。実ソースから生成した旧保存の一致検証は、未確認の全中間版を網羅した保証ではありません。
