# 戦闘・遠隔・護衛の操作

確認・更新日: 2026-10-24

## 遠隔部隊で試す

1. 「遠隔部隊の二国対戦」を選び「新規開始」を押します。残したい対局は先にセーブしてください。
2. 各国に戦士2・弓兵2・弩砲1の隣接部隊があります。敵の駒か攻撃対象一覧を選びます。自軍の選択は保持します。
3. 攻撃種別を「遠隔」にし、攻撃内容を選びます。弓兵は狙い射ち・精密射撃・横列、弩砲は縦列・十字・貫通を使います。
4. Unit・配置枠・横列・縦列を指定します。敵配置をクリックしても照準を変更できます。クリックだけでは攻撃しません。
5. 命中率・対象範囲・Unit別HP損失・護衛・反撃を確認し「攻撃する」を押します。
6. 「ターン終了」で相手国へ交代します。都市、生産、購入も手番の王国へ切り替わります。双方を人が操作し、AIは動きません。

従来の「二国対戦（交互操作）」は戦士3体ずつです。戦士だけの部隊では遠隔攻撃できません。通常の新規開始と旧37セルの保存も維持します。

弓兵はProduction18／Gold72、弩砲はProduction28／Gold112で都市から生産・購入できます。生産直後は未編成で都市に待機するので、移動する場合はPartyを作ります。専用画像の代わりに「弓」「弩」バッジで表示します。

## 攻撃内容と照準

| 攻撃 | 照準 | 挙動 |
| --- | --- | --- |
| 通常 | 自動 | 各列の露出UnitからTauntを優先して1体を選び、命中 |
| 狙い射ち | Unitか配置枠 | 後列も狙える。失敗すると前方Coverへ命中し、Coverなしなら被害なし |
| 精密射撃 | Unitか配置枠 | 命中率に5ポイント加算。失敗時は被害なし |
| 横列への一斉射撃 | 前・中・後 | 同じ横列の生存Unitへ各0.5倍 |
| 縦列砲撃 | 左・中央・右 | 同じ縦列の生存Unitへ各0.65倍 |
| 十字砲撃 | 中心枠 | 中心と縦横隣接へ各0.5倍。斜めは含まない |
| 貫通射撃 | 左・中央・右 | 生存Unitを前から1倍・0.6倍・0.36倍。空き枠とHP0は飛ばす |

狙い撃ちの空き枠は攻撃できません。十字の中心が空でも、十字内に生存Unitがいれば攻撃できます。射程、兵種、対象、残り行動の条件を満たさないと、理由を表示して攻撃ボタンを無効にします。照準変更は行動や乱数を消費しません。

狙い撃ちの命中率には射手accuracy、対象evasion、同列前方1体のCover、他の露出Unit1体のTauntが作用します。明示した対象をTauntで別Unitへ強制変更しません。狙い射ちがCoverに当たった場合、そのCoverを守るGuardが発動する場合があります。

## 護衛を設定する

自軍の護衛役・守るUnit・方式を選び「護衛設定を適用」を押します。同一Party内の配置距離と能力を検証します。設定は行動を消費せず保存され、配置変更後に範囲外になった場合や戦闘不能時は発動しません。

新規戦士は護衛率50％・容量50・縦横距離1。旧保存の率0・容量0を変えません。肩代わりは装甲前Damage×率を切り捨て、最大70％・残り容量までを引き受けます。割り込みは全量を受け、Partyの反応を1消費し、Guard容量は消費しません。

候補が複数なら割り込み→距離→ID順で1体を選び、連鎖しません。stun／break／fearの護衛役は除外します。範囲攻撃では主対象にだけ1回発動し、同じUnitへの直撃と肩代わり・割り込みを合算してから装甲を1回適用します。

## 予測と戦闘後

予測は戦闘RNGを参照・更新せず、起こり得るDamage・命中失敗・護衛・HP0・反撃を含むHP損失範囲です。配置の攻撃範囲と、護衛等を含む被害対象を区別します。確定値ではありません。配置・能力は現在すべて公開情報です。

攻撃後は攻撃回数1消費・移動力0・行動終了です。外れても同じです。近接では生き残った相手が通常反撃し、防御側の攻撃回数・反応を消費しません。遠隔には標準反撃がありません。両国の手番が一巡すると行動・護衛容量・反応を回復し、HPは自然回復しません。

HP0の戦士・弓兵・弩砲はshatteredとなり、指揮官なら生存者へ継承します。全員戦闘不能なら敗北です。敗北した駒は地図の占有から外れ、撃破地点へ移動・通過できます。Party・Unit・配置・位置は保存され、セル詳細の敗北記録から確認できます。自動前進・捕虜・戦利品はありません。交互操作にはゲーム終了条件はなく、AIとの遭遇戦では全敵活動部隊撃破が勝利条件です。

最新18件の戦闘ログを表示し、Miss／Cover／Tauntも記録します。音声オンでは敵選択中に戦闘BGM、護衛発動時は護衛SE、それ以外の被弾時は命中SEを1操作1音で鳴らします。専用射撃音は未制作です。ロードで古いログを再生しません。

詳細: [遠隔仕様](RANGED_COMBAT.md)・[現行実装](CURRENT_IMPLEMENTATION.md)・[遠隔QA](../assets/qa/browser-ranged-2026-10-24.json)・[従来操作と音声QA](../assets/qa/browser-grid-2026-10-24.json)。人による聴取は未実施です。

## AIとの遭遇戦

新規ゲームで「AIとの遭遇戦」を選び「新規開始」を押します。人は黎明王国、AIは夕映王国を操作します。各軍は戦士2・弓兵2・弩砲1です。ターン終了後、AIは移動・通常攻撃を行って手番を返します。AI手番中は地図・ログの確認とセーブができ、自軍の行動は停止します。

全敵活動部隊を撃破すると勝利、自軍の全活動部隊を失うと敗北です。都市・待機Unitが残っていても終了します。40ターン目の両国終了で引き分けです。結果は地図上部に表示し、保存・復元できます。次の対局は「新規開始」から始めます。途中セーブのロードはAI手番を再開します。[規則と制約](AI_SCENARIOS.md)。

## AIとの増援戦

新規ゲームで「AIとの増援戦」を選んで開始します。配置と勝敗条件は遭遇戦と同じですが、AIは都市で兵を生産・購入し、1〜5体で増援部隊を作ります。都市の出口を自軍が塞いでいれば移動して空けます。直近の手番の生産・購入・編成・移動・攻撃回数は地図上部に表示します。途中セーブ・ロードで購入上限と生産進捗を保持します。旧遭遇戦は移動・攻撃のみのままです。[AIの判断と予算](AI_SCENARIOS.md)。

## 部隊の再編

選択部隊の「部隊の再編」から、同じセルの待機兵を補充、隣接部隊へ合流、一部の構成員を空き隣接セルへ分割できます。選択だけでは状態を変えず、実行ボタンで確定します。条件を満たさない理由を表示します。関係部隊は未終了・移動力1以上が必要で、合流・分割は進入地形費も満たす必要があります。最大5体は戦闘不能者を含みます。

成功後は関係する全部隊の移動・攻撃・反応が0になり、そのターン終了します。HP・護衛残量を回復しません。合流先・分割で生まれた部隊を自動選択し、ロードでは編集中の選択を解除します。AI手番中と対局終了後は実行できません。増援AIも同じCommandで補充・合流します。[規則と保存](PARTY_MANAGEMENT.md)。

## 都市争奪戦と占領

新規ゲームで「AIとの都市争奪戦」を選びます。敵都市に守備部隊がいれば撃破し、軍事部隊を都市中心へ移動して「都市占領」を押します。攻撃回数1以上・行動未終了が必要で、移動力0でも占領できます。成功時は移動・攻撃・反応を終了します。人口・建物・領土を引き継ぎ、生産予約と進捗を解除、収入は次の全体ターン開始からです。

全都市を失うと敗北します。軍隊全滅だけでは終了せず、都市から再建できます。AIも占領を行い、都市0の敗者は「所有都市なし」と表示して、地図・部隊記録・保存を使えます。[占領と勝敗の詳細](CITY_CONQUEST.md)。
