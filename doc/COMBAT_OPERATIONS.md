# 戦闘と護衛の操作

確認日: 2026-10-18

## 二国で試す

1. 新規ゲームで「二国対戦（交互操作）」を選び「新規開始」を押します。現在の対局を置き換えるため、残したい場合は先にセーブしてください。
2. 黎明王国の部隊が選択され、夕映王国の部隊が隣接しています。各部隊は戦士3体です。
3. 敵の駒か「戦闘と護衛」の攻撃対象一覧を選びます。自軍の選択は保持され、敵は赤枠になります。
4. 近接の予測HP損失・反撃・護衛を確認し「攻撃する」を押します。クリックで敵を選ぶだけでは攻撃しません。
5. 「ターン終了」で夕映王国を操作します。都市・生産・購入も手番の王国へ切り替わります。双方を人が操作し、AIは動きません。

双方の手番が一巡すると都市収支と行動・護衛容量・反応の回復を行います。HPは自然回復しません。攻撃すると攻撃回数1を消費し、その部隊の移動力は0、行動終了です。近接の通常反撃は防御側の攻撃回数・反応を消費しません。戦士に遠隔能力はなく、遠隔を選ぶと理由を表示して攻撃を無効にします。

## 護衛を設定する

自軍の「護衛するUnit」「守るUnit」「護衛方式」を選び「護衛設定を適用」を押します。3×3配置内の距離と能力を検証し、設定自体では移動力・攻撃回数を消費しません。設定は保存され、配置変更後に範囲外になった場合や戦闘不能時は発動しません。

新しく作る戦士は護衛率50％、容量50、縦横距離1です。2026-10-18、単体護衛の初期バランスとして採用しました。既存セーブの率0・容量0は維持し、能力を後から増やしません。護衛範囲がない旧保存には既定距離1、護衛指示がない旧Partyには空の指示を補完します。

肩代わりは、装甲適用前Damage×率を切り捨て、残り容量まで引き受けます。率は最大70％。容量消費は装甲前の引受量で、元の対象と護衛役にそれぞれ装甲・最低被害1を適用します。実HP損失は残りHPまでです。

割り込みは全Damageの対象を護衛役に変更し、部隊のreactionChargesを1使います。Guard容量は消費しません。複数候補は割り込み優先、枠間距離が短い順、ID昇順で1体を選び、護衛の連鎖は起こしません。stun／break／fearの護衛役は除外します。これらの状態を付与するAbilityはまだありません。

## 対象・予測・結果

通常攻撃は正面から各列の最初の生存Unitを露出候補とし、前寄り、中央、左、右の順で選びます。空いた枠を自動で詰めません。後方・側面の露出ヘルパーは内部にありますが、攻撃方向を指定する操作はありません。

予測は戦闘RNGを参照・更新せず、起こり得る整数Damageと反撃の上下限を試算します。護衛容量、HP0、指揮官交代、反撃消滅の分岐を含む両軍各UnitのHP損失範囲です。確定値ではありません。現在は霧・非公開情報の仕組みがなく、画面に公開されている状態を使います。

画面には敵の配置とHP、最新18件の戦闘ログ、短い被弾表示があります。音声オンの場合、敵を選択中は戦闘BGM、護衛・割り込み発生時は護衛SE、それ以外の被弾時は命中SEを1操作1音で鳴らします。ロードで過去のログを再生しません。

HP0では戦士はshatteredとなり、指揮官なら生存者へ継承します。全員戦闘不能なら敗北です。敗北部隊の盤上占有は残ります。撤去・撤退・回復・捕虜・戦利品・勝利判定、Taunt／Cover・狙い撃ち・範囲・貫通は未実装です。
