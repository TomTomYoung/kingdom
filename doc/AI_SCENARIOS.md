# 戦術AIと遭遇戦

確認日: 2026-10-30。開始基準: main / 78cd406（PR #6）。[現行実装](CURRENT_IMPLEMENTATION.md)・[操作](COMBAT_OPERATIONS.md)・[検証](STATUS.md)。

## 遊び方と範囲

「AIとの遭遇戦」を選び「新規開始」を押すと、人が黎明王国、AIが夕映王国を操作します。各国は1都市と戦士2・弓兵2・弩砲1の部隊を持ち、部隊位置は1,-1,0と6,-6,0です。接近用にq=1〜6の(q,-q,0)を平原にします。既存の開拓と二国交互操作は維持し、勝敗を後付けしません。

AIは通常の遠隔・近接攻撃と移動を行います。都市生産・購入・増援編成・都市建設、範囲や狙い撃ちの選択、配置・護衛の再設定、撤退、戦略評価は後続です。人は既存の都市操作・編成・7攻撃を使えます。対等な都市運営AIや完成した難易度調整ではありません。

## 決定論と手番

`AIController.nextCommand`は状態を変更せず、次のRNGも読みません。ID順の自軍・敵軍から即時の通常遠隔攻撃、できなければ近接攻撃を探します。攻撃がなければ地形費を使うDijkstraで合法な射程位置への経路を求め、当ターンの移動力内の接頭経路を選びます。Voidと他の活動部隊を避け、敗北記録は占有しません。民間Unitだけの部隊を攻撃のために移動させません。

選択したCommandは全てRuleSystemで検証・実行します。合法な移動や攻撃がなければEndTurnです。通常命令は最大128回、その後はEndTurnを強制し、行動不能でも手番が進みます。coreの`runAiTurn`は呼出しごとの上限、UIは同一王国・同一ターンの保存済み命令数を使います。命令失敗はループせず停止し、UIに理由と再開ボタンを表示します。

UIは約180msごとに1命令を適用します。人の表示国・都市・選択を保持し、自軍の変更操作を止めます。地図・戦闘ログの閲覧とセーブは可能です。ロードでAI手番を自動再開し、新規開始・別保存のロード・ページ離脱時は旧タイマーを取り消します。タイマーや表示選択はGameStateに保存しません。

## 終了規則

遭遇戦は`scenarioObjective = { type: 'eliminate-parties', participantIds: ['kingdom-1', 'kingdom-2'], turnLimit: 40 }`を持ちます。期限は暫定値です。

- 活動中で生存Unitを含む部隊が片方の王国にしかなければ、その王国の勝利です。後から編成した部隊も含み、都市・未編成Unitは判定から除きます。
- 両国とも対象部隊がなければ引き分けです。
- 撃破による決着がなく40ターン目の両国手番が終われば引き分けです。41ターン目の収入・行動値回復の前に止めます。

成功Command後に判定するため、近接反撃による攻撃側の敗北も結果へ反映します。終了時は`phase = 'GAME_OVER'`とし、`gameResult`へoutcome（victory/draw）、winnerId（勝者またはnull）、reason（elimination/turn-limit）、turnを保持し、ScenarioFinishedを1回記録します。終了後の全Commandは元state・空eventsで拒否します。画面は勝利・敗北・引き分けを表示し、閲覧・保存・復元・新規開始を許可します。

これは全敵部隊撃破のScenario Objectiveです。都市占領・首都喪失・降伏によるDomination、Dungeon Conquest、Scoreは実装していません。

## 保存互換と検証

目標と結果は組で保存し、参加国・期限・phase・生存部隊・勝者・終了理由・終了ターン・期限時の一巡を検証します。不正な勝者や未終了の全滅状態を拒否します。旧モードは目標と結果の両方がない状態を維持します。controllerTypeはhuman/aiを認め、旧保存の省略だけhumanへ補完します。

`tests/ai-scenario.test.js`は判断の不変性、RNG非参照、通常移動・攻撃・手番、迂回・占有・民間・行動上限、途中再開、勝利・敗北・反撃・期限、全Command拒否、保存の整合性、AI同士の対局完了を確認します。

実ブラウザQAは任意の開発依存Playwrightを使います。ゲーム本体への依存は追加しません。

```sh
KINGDOM_QA_MODULES=/path/to/node_modules node tools/qa/browser-ai.mjs /tmp/kingdom-ai-qa
```

`KINGDOM_BROWSER`でChromium実行ファイルを指定できます。UIの手番・ロック・途中ロード・取消・3結果・不正保存・390px表示・交互操作を検証します。
