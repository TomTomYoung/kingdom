# リソース一覧

[Wiki入口](../README.md)

資源はすべて同じ財布へ貯まるわけではありません。都市の成長や生産に使う量、王国が蓄える通貨、累積進捗を区別して運用します。

## 現在の8項目

| リソース | 保持・集計の単位 | 現在の用途 |
| --- | --- | --- |
| [食料](./food.md) | 都市の備蓄 | 人口成長 |
| [生産](./production.md) | 都市の生産対象別進捗 | 戦士・モニュメントの完成 |
| [Gold](./gold.md) | 王国の備蓄 | ユニット・建物・領土の即時購入、軍事力の算出 |
| [科学](./science.md) | 王国の累積進捗 | 軍事力の算出。技術解禁は未実装 |
| [mana](./mana.md) | 王国の備蓄 | 軍事力の算出。消費用途は未実装 |
| [宗教](./religion.md) | 都市のターン産出 | 集計・表示のみ |
| [文化](./culture.md) | 王国の累積進捗と都市の拡張進捗 | 自然領土拡張、統治力の算出 |
| [人心](./popular-support.md) | 王国の備蓄 | 固定収入と王国単位の維持費処理。加入は未実装 |

食料から文化までの7項目が都市の産出です。人心はこの産出合計に含まれず、王国単位で収支を計算します。都市の産出は、[市民が働く地形](../terrain/README.md)、建物、都市の基礎産出から得ます。

## 関連する人口・能力

[人口と人的資源](../rules/population.md) は人員を表します。[軍事力・統治力・負荷](../rules/governance.md) は資源や施設などから求める指標です。どちらもGoldと交換可能な一種類の通貨としては扱いません。

鉄・馬などの個別戦略資源、ダンジョン素材、装備・消耗品の正式な種類はまだありません。将来の用途は設計されていますが、採掘資源やアイテムの完成済みリストは存在しません。
