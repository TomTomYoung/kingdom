# Wikiの更新方法

[Wiki入口](./README.md)

Wikiはプレイヤーが名称・効果・条件・費用を調べるゲーム事典です。開発上の作業順や不具合の再現手順はdocで管理し、Wikiから必要な箇所を参照します。

## 記載する状態

「現在」はコードと通常画面の実挙動から記載します。処理だけ存在して画面から呼べないものは、その範囲を明示します。「予定」はdocで決まっている目標です。名称・費用・解禁条件が未定なら未定と書きます。

既知不具合による挙動を能力や攻略規則として正当化しません。保存欄、制作済み素材、目標仕様の存在だけで、ゲーム内利用が実装済みとは判断しません。Civilizationの固有コンテンツを自動でKingdomへ補いません。

## 新しい項目

1. 該当カテゴリに英小文字のファイル名で個別ページを作ります。現在の識別子がある場合はそれに合わせます。
2. 冒頭に名称、用途の説明、現在の実装・画面の状態を記載します。
3. 費用・能力・産出・条件を出典と照合します。未使用の数値は、実効効果のある数値と区別します。
4. 入手・利用・関連項目を記載し、末尾へ根拠となるコードと設計文書をリンクします。
5. カテゴリ一覧、Wiki入口、用語索引、関連項目からのリンクを更新します。

画像はassets内の採用する版への相対リンクを使います。新規素材は既存方針に従いAIPaintのドット絵で制作します。音声を追加する場合はAIMusicを使い、原稿・ジョブ・確認結果を保存します。

## 変更時に確認する組み合わせ

| 変更 | 更新・照合するWiki |
| --- | --- |
| 地形の産出や移動費 | 地形一覧・個別地形・各資源・都市配置・移動 |
| ユニットの費用や能力 | ユニット一覧・個別ユニット・生産・戦闘 |
| 建物や区画 | 対象一覧・個別項目・都市・関連資源・統治負荷 |
| ターンや初期値 | ターンページ・資源ページ・人口・統治指標 |
| 新しい画面操作 | 行動一覧・対象のページ・Wiki入口の利用範囲 |
| 新技術・能力・ダンジョン | 該当分野の一覧と個別項目、解禁先、用語索引 |

数値は現行コードを正本として照合し、設計目標との相違は状態を分けて残します。未実装の予定仕様が正式に変わる場合は、該当docも更新して決定を記録します。
