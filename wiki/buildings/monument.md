# モニュメント

[建物一覧](./README.md) · [Wiki入口](../README.md)

![モニュメント](../../assets/graphics/building-monument/v001/image.png)

都市の文化産出を増やす建物です。自然な領土拡張を早め、文化の蓄積を通じて王国の統治力にも寄与します。

現在: 生産・購入・産出効果を利用できます。識別子は `monument` です。

| 項目 | 値 |
| --- | --- |
| 生産費 | 生産20 |
| 即時購入 | Gold 80 |
| 都市への効果 | 毎ターン文化+2 |
| 建設条件 | 技術・区画などの前提条件なし |
| 所属 | 生産・購入した都市 |
| 所有数 | 都市の建物一覧への登録は1件まで |

文化以外の直接産出はありません。現在の[統治指標](../rules/governance.md)では、建物が1件増えること自体によって統治力と負荷がそれぞれ1増えます。

完成したその回の産出計算には間に合わず、文化+2は次回のターン開始処理で加算されます。購入でも産出の即時受け取りはありません。

建設済みのモニュメントを再購入する操作は拒否されます。一方、重複生産の選択や、生産途中で購入した後のキュー処理には既知の不具合があります。重複登録による文化の上乗せはありませんが、生産を浪費する場合があります。[既知課題K-08](../../doc/STATUS.md) を参照してください。
