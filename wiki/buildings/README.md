# 建物一覧

[Wiki入口](../README.md) · [区画一覧](../districts/README.md) · [都市と生産](../rules/cities.md)

建物は都市に所属し、産出などに効果を与えます。現在の建物は2種類です。城壁は新規都市争奪戦で利用できます。

| 建物 | 生産費 | 即時購入 | 効果 |
| --- | ---: | ---: | --- |
| [モニュメント](./monument.md) | 生産20 | Gold 80 | 都市の文化産出+2 |
| [城壁](./walls.md) | 生産30 | Gold 120 | 城壁HP60。新規都市争奪戦のみ |

個別Hexへ建物を配置する操作や、建物を収容する区画の選択はありません。遺産（Wonder）と都市プロジェクト（Project）は将来の生産分類で、具体的な建設対象は未定です。

根拠: [生産対象定義](../../src/core/ruleset.js)、[生産・完成処理](../../src/systems/production-system.js)。
