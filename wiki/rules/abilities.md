# 能力と状態

[Wiki入口](../README.md) · [戦闘](./combat.md) · [ユニット一覧](../units/README.md)

ユニットの基礎能力、戦闘中の状態、個別に発動するスキルや魔法は別のものです。値を保存する欄があっても、その効果まで動くとは限りません。

## 現在働く値と状態

| 項目 | 現在の効果 |
| --- | --- |
| HP・active | 戦闘力へ参加できるか、被害対象になるかを決める |
| 近接・遠隔・防御の戦闘力 | パーティーの平均戦闘力へ使用 |
| 装甲 | 対象ユニットの被害を減らす。最低被害1 |
| 射程 | 攻撃対象までの距離を制限 |
| 結束 | パーティー戦闘力へ「0.5 + 結束 / 200」を掛ける |
| 指揮寄与 | 指揮官が倒れたときの継承順に使用 |
| 移動力・攻撃回数 | パーティーの移動・攻撃を制限 |
| downed・shattered | HP0後の戦闘不能状態 |
| defeated | パーティー敗北。攻撃側として攻撃を開始できない |

敗北パーティーの移動を完全には止められていない不具合があります。また、結束は初期100を使いますが、戦闘で結束を変化させる処理はありません。

## 記録はあるが効果の一部が未接続の値

| 項目 | 現在の範囲 |
| --- | --- |
| 士気 | 被害・指揮官継承で低下。能力補正や士気0撤退は未実装 |
| 忠誠 | 戦士の初期値100。変動と命令拒否は未実装 |
| 抵抗・魔法戦闘力 | 保存値あり。魔法や抵抗による被害処理は未実装 |
| Guard容量 | 保存・ターン回復あり。肩代わり未実装 |
| リアクション回数 | パーティー初期1・ターン回復あり。専用反応での消費は未実装 |
| チャージ・能力状態・状態効果 | ユニットに保存欄あり。個別能力の実行処理は未実装 |

## 予定されている能力

Guardは被害の一部を肩代わりし、Interceptは主な被害対象を自分へ変更し、Tauntは対象未指定攻撃を引きつける役割です。Coverや狙い撃ち、範囲・貫通攻撃も設計されています。

スキル・魔法は移動力、攻撃回数、有限チャージ、mana、Gold、再使用待ち時間などの個別費用・制限を持つ方針です。職業・スキル・呪文・状態異常の正式な個別定義はまだありません。ここに挙げた仕組みを、戦士がすでに習得している能力として扱いません。
