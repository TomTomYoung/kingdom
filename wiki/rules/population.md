# 人口と人的資源

[Wiki入口](../README.md) · [都市](./cities.md) · [食料](../resources/food.md)

人口は都市に暮らす人数の規模、人的資源は王国が運用する人員の区分です。現行では両者を別の値として持ちます。

## 都市人口

各都市の初期人口は2です。その都市に所属する自国の非Voidタイルへ人口数まで市民を自動配置し、働くタイルの産出を得ます。所属タイルが足りなければ働く枚数は人口より少なくなり、他都市のタイルは借りません。食料が「12 + 現在人口×6」に達すると、それを消費して人口が1増えます。

食料備蓄と成長判定は都市ごとに独立しています。成長して増えた市民は次回の産出計算から働き、画面の作業一覧は収集時点の記録です。

現在は人口による食料消費、飢餓、住宅、快適性、移住の処理はありません。人口が増えるたびに統治負荷が1増えますが、負荷超過による罰則もまだありません。

## 王国の人的資源

| 区分 | 初期値 | 現在の利用 |
| --- | ---: | --- |
| 国内人員（native） | 1 | 人口成長時に+1 |
| 軍事人員（military） | 0 | 1につき軍事力+2 |
| 統治人員（governance） | 1 | 1につき統治力+2 |
| 専門家（specialists） | 0 | 保持欄のみ |
| 英雄（heroes） | 0 | 保持欄のみ |
| 国外関係人員（affiliates） | 0 | 保持欄のみ |
| 移民（migrants） | 0 | 保持欄のみ |

国内人員1と都市人口2は別々の初期値です。国内人員を徴募して軍事人員へ移す操作はありません。[戦士](../units/warrior.md)の生産・購入でも人口や国内人員を消費しません。

## 予定

教育・徴募・訓練・登用によって人口を各人員区分へ移し、軍隊、統治、研究、専門職として使う方針です。外国の支持者と、自国へ移住した人員も分けます。

国外人材は接触・帰属意識・募集可能状態を経て、[人心](../resources/popular-support.md)などで加入させ、王国へ統合する設計です。現在、個別人材の一覧や募集画面はありません。
