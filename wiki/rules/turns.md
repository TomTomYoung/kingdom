# ターン・開始時の状態・保存

[Wiki入口](../README.md) · [行動一覧](./actions.md)

都市と王国の収入はターン開始時に処理します。リアルタイム経過で資源が増えるゲームではありません。

現在: 通常の一王国、同じ王国の二都市を運営するモード、二国を交互に操作するモードがあります。新規ゲームの選択欄から二国対戦を開始できます。敵を含め双方を人が操作し、ターン終了で王国・都市が切り替わります。別の「AIとの遭遇戦」では敵が自動で移動・攻撃・手番終了し、自分の都市表示を維持します。AI手番中の行動は停止しますが地図確認・セーブは可能です。途中ロードはAIを再開します。任意の参加者設定・オンライン通信は未実装です。

## ターンの流れ

1. ターン開始時、人心の維持費支払いと収入、都市産出、人口成長、生産、備蓄と進捗、文化拡張、パーティー行動値回復を処理します。
2. 手番の王国が都市操作やパーティー移動などを行います。
3. 「ターン終了」で次の王国へ移ります。すべての王国の手番が一巡するとターン数が増え、全王国の次の開始処理を行います。

各都市の産出は、その都市に所属するタイルだけから計算します。食料・生産・領土文化は都市ごとに処理し、Gold・mana・科学・王国文化は各都市分を王国へ合算します。画面で都市を切り替えても収入・手番・乱数は変化しません。

遭遇戦は全敵活動部隊撃破で即終了、40ターン目の一巡で引き分けになります。終了後の収入・行動はありません。結果を保存・復元できます。[勝敗の詳細](victory.md)。

現在は各王国への手番切替ごとに収入が入るのではなく、一巡後の新ターン開始に全王国を処理します。一王国の通常画面では「ターン終了」で直ちに次のターンへ進みます。

## 通常の新規開始

固定seed 117、半径10・331セルの地図で黎明王国・暁都から始まります。首都に戦士1体の部隊があり、すぐに操作できます。最初の画面は第1ターンの開始処理を済ませた状態です。

| 項目 | 初期画面の値 |
| --- | --- |
| ターン | 1 |
| 人口・食料 | 人口2、食料5 / 成長に必要な24 |
| Gold・mana・人心 | 102・0・31 |
| 科学・文化進捗 | 1・2 |
| 都市の領土拡張進捗 | 2 / 10 |
| 都市産出 | 食料5、生産4、Gold 2、科学1、mana 0、宗教0、文化2 |
| 軍事力・統治力・負荷 | 12・5・11 |
| 領土・ユニット・パーティー | 7Hex・1・1 |

生産対象は未選択なので、この最初の生産4は備蓄されません。生産を選択すると次回開始から進みます。上の値は現在の固定マップと自動市民配置に基づくもので、別seedやルール変更後も同じとは限りません。

## 二都市運営の開始

「二都市運営」→「新規開始」で、黎明王国の暁都と東都から始まります。両都市とも人口2、中心と周囲の初期領土を持ちます。首都の戦士1体の部隊を維持し、Gold等の王国備蓄は共通です。

「操作する都市」で切り替えると、その都市の食料・文化・生産・建物・収集内容を表示し、購入と領土取得の対象も変わります。新都市を建設する操作ではなく、開始時の二都市セットアップです。

## 二国対戦の開始

各国1都市・戦士3体の部隊が隣接して始まり、先手は黎明王国、後手は夕映王国です。通常開始の上表とは異なるセットアップです。初期配置には肩代わり護衛が設定されています。新規戦士の護衛率は50％・容量50・範囲1。二国で一巡すると行動・容量・反応を回復します。[戦闘操作](../../doc/COMBAT_OPERATIONS.md)を参照してください。

「遠隔部隊の二国対戦」では各国の部隊が戦士2・弓兵2・弩砲1の5体です。通常の二国対戦（戦士3体ずつ）も選べます。範囲・貫通は弩砲、狙い撃ち・横列射撃は弓兵が担当します。

## 保存と再開

「セーブ」は現在のブラウザの保存領域へ記録し、「ロード」で復元します。ファイルのダウンロード・アップロードによるセーブ操作は現在の画面にありません。「新規開始」は同じ固定seedで状態を作り直します。

保存では資源・ユニット・パーティー・配置・乱数状態・行動ログなどを保持します。ロード前に地形・都市・所属・配置・HP・行動値・手番・乱数などを検証し、壊れたデータは拒否します。失敗した場合は現在の対局と選択・地図倍率を維持します。既知の旧M1データを補完しますが、すべての旧中間版からの移行を保証するものではありません。

ロード時は部隊・Unitと攻撃の照準を解除して首都を表示します。遠隔二国対戦と二都市運営のモードは保存から復元します。選択都市は保存せず、ロード時に手番の王国の首都へ戻ります。旧37セルのセーブも地形・範囲・所有国・Unitを保持して復元します。所属都市がない旧保存には一度だけ所属を補完し、同じ王国に複数都市がある場合は重複作業を解消します。移行で収入を再加算したり、乱数を進めたりしません。広いマップと初期戦士は新規開始に適用し、新規開始時には初期部隊を選択します。選択後のクリック挙動など、操作上の制約は [STATUS](../../doc/STATUS.md) に記録されています。

「開拓者と護衛」は戦士1・開拓者1の部隊と暁都で始まります。都市建設時は収入処理を行わず、建設した都市は次の全体ターン開始から収集に参加します。セーブは都市連番を保持し、旧形式の欠落は既存都市IDから安全な次番号を補完します。[建設の詳細](../../doc/CITY_MANAGEMENT.md)。
