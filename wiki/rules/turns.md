# ターン・開始時の状態・保存

[Wiki入口](../README.md) · [行動一覧](./actions.md)

都市と王国の収入はターン開始時に処理します。リアルタイム経過で資源が増えるゲームではありません。

現在: 通常の一王国と、二国を交互に操作するモードがあります。新規ゲームの選択欄から二国対戦を開始できます。敵を含め双方を人が操作し、ターン終了で王国・都市が切り替わります。AI・任意の参加者設定・オンライン通信は未実装です。

## ターンの流れ

1. ターン開始時、人心の維持費支払いと収入、都市産出、人口成長、生産、備蓄と進捗、文化拡張、パーティー行動値回復を処理します。
2. 手番の王国が都市操作やパーティー移動などを行います。
3. 「ターン終了」で次の王国へ移ります。すべての王国の手番が一巡するとターン数が増え、全王国の次の開始処理を行います。

現在は各王国への手番切替ごとに収入が入るのではなく、一巡後の新ターン開始に全王国を処理します。一王国の通常画面では「ターン終了」で直ちに次のターンへ進みます。

## 通常の新規開始

固定seed 117、半径10・331セルの地図で黎明王国・暁都から始まります。首都に戦士1体の部隊があり、すぐに操作できます。最初の画面は第1ターンの開始処理を済ませた状態です。

| 項目 | 初期画面の値 |
| --- | --- |
| ターン | 1 |
| 人口・食料 | 人口2、食料5 / 成長に必要な24 |
| Gold・mana・人心 | 102・0・31 |
| 科学・文化進捗 | 1・2 |
| 都市の領土拡張進捗 | 2 / 10 |
| 都市産出 | 食料5、生産4、Gold 2、科学1、mana 0、宗教0、文化2 |
| 軍事力・統治力・負荷 | 12・5・11 |
| 領土・ユニット・パーティー | 7Hex・1・1 |

生産対象は未選択なので、この最初の生産4は備蓄されません。生産を選択すると次回開始から進みます。上の値は現在の固定マップと自動市民配置に基づくもので、別seedやルール変更後も同じとは限りません。

## 二国対戦の開始

各国1都市・戦士3体の部隊が隣接して始まり、先手は黎明王国、後手は夕映王国です。通常開始の上表とは異なるセットアップです。初期配置には肩代わり護衛が設定されています。新規戦士の護衛率は50％・容量50・範囲1。二国で一巡すると行動・容量・反応を回復します。[戦闘操作](../../doc/COMBAT_OPERATIONS.md)を参照してください。

## 保存と再開

「セーブ」は現在のブラウザの保存領域へ記録し、「ロード」で復元します。ファイルのダウンロード・アップロードによるセーブ操作は現在の画面にありません。「新規開始」は同じ固定seedで状態を作り直します。

保存では資源・ユニット・パーティー・配置・乱数状態・行動ログなどを保持します。ロード前に地形・都市・所属・配置・HP・行動値・手番・乱数などを検証し、壊れたデータは拒否します。失敗した場合は現在の対局と選択・地図倍率を維持します。既知の旧M1データを補完しますが、すべての旧中間版からの移行を保証するものではありません。

ロード時は部隊・Unitの選択を解除して首都を表示します。旧37セルのセーブも、マップとUnitを追加変更せずに復元します。広いマップと初期戦士は新規開始に適用し、新規開始時には初期部隊を選択します。選択後のクリック挙動など、操作上の制約は [STATUS](../../doc/STATUS.md) に記録されています。
