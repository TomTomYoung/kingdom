# 戦闘

[Wiki入口](../README.md) · [パーティー](./parties.md) · [ユニット一覧](../units/README.md)

パーティー全体の戦闘力で攻防を計算し、構成ユニットが被害を受けます。人数は攻撃回数になりません。二国交互操作、予測、攻撃・反撃、護衛・割り込み、挑発・遮蔽、狙い撃ち・範囲・貫通を実装しています。[操作手順](../../doc/COMBAT_OPERATIONS.md)と[遠隔戦闘の実装仕様](../../doc/RANGED_COMBAT.md)を参照してください。

## 攻撃と反撃

近接は隣接敵が対象です。先に攻撃側の被害を解決し、防御側に戦闘可能な構成員が残れば反撃します。通常反撃は攻撃回数・リアクション回数を使いません。

遠隔は射程内の敵が対象で、標準の反撃を受けません。遠隔戦闘力が正で生存したUnitのうち、自身の射程が届き、その攻撃定義の種類に合うUnitだけが攻撃力へ寄与します。戦士だけでは射撃できず、射程3の弩砲で射程2の弓兵を延長できません。

攻撃は攻撃回数1を消費し、移動力0・行動終了になります。命中失敗でも同じです。撃破後の自動前進はありません。

## 7種類の攻撃

| 攻撃 | 必要Unit | 照準・倍率 |
| --- | --- | --- |
| 通常攻撃 | 近接は全生存Unit、遠隔は射程内の遠隔Unit | 露出と挑発で自動選択、100% |
| 狙い射ち | 弓兵 | Unitまたは枠、100%。失敗時は遮蔽役へ |
| 精密射撃 | 弓兵 | Unitまたは枠、100%。命中+5ポイント、失敗時は被害なし |
| 横列への一斉射撃 | 弓兵 | 前・中・後列、各50% |
| 縦列砲撃 | 弩砲 | 左・中央・右の縦列、各65% |
| 十字砲撃 | 弩砲 | 中心と縦横の隣接枠、各50% |
| 貫通射撃 | 弩砲 | 指定縦列の生存対象へ前から100%、60%、36% |

狙い撃ちの空枠指定は拒否します。十字の中心は空でも範囲内に生存対象がいれば攻撃できます。範囲内の対象を攻撃開始時に固定します。空枠・戦闘不能に配分を移さず、貫通では生存した対象だけを深さに数えます。余剰被害の繰り越しはありません。

## 戦闘力と被害

参加Unitの対応能力平均へ「0.5 + 結束 / 200」を掛けます。防御側は全生存Unitの防御力平均を使います。結束100なら倍率1。王国の表示用軍事力は使いません。

Aを攻撃力、Bを防御力、Rを0.85以上1.15未満の戦闘乱数として、基礎Damageは `round(clamp(30 × exp(0.04 × (A − B)) × R, 1, 90))` です。攻撃ごとに基礎Damageを1回だけ引き、各対象の倍率を掛けて切り捨てます。護衛による配分後、同じUnitの直撃と肩代わりを合計し、装甲を1回引きます。正の配分には最低被害1、配分0には被害0です。実際のHP損失は残りHPを超えません。

通常と範囲・貫通は常に命中します。狙い撃ちは参加者の命中率平均から標的の回避率、遮蔽、露出した他の挑発役1体の値を引き、0〜100%へ制限します。精密射撃だけ5ポイント加算します。予測は実際の乱数状態を読まず、命中・失敗・反撃を含むHP損失の最小〜最大を示します。

## 露出・挑発・遮蔽・護衛

通常は各縦列の先頭生存Unitを候補とし、有効な挑発が強い順、同値なら前寄り・中央・左・右の順で選びます。手動照準は挑発で対象を変えません。

遮蔽は狙うUnitと同じ縦列で、その前にいる最初の有効な遮蔽役1体です。stun・break・fear中と戦闘不能のUnitは挑発・遮蔽・護衛を行いません。配置は空き枠ができても自動で前へ詰まりません。

Guardは装甲前Damageの一部を容量内で肩代わりし、Interceptは主対象分を全量受けて部隊の反応1を消費します。新規戦士は肩代わり50%・容量50・縦横距離1。複数候補は割り込み、近い枠、ID順で1体を選び、連鎖しません。範囲攻撃では主対象にだけ1回適用し、範囲全体を吸収しません。

## HP0・士気・敗北

IndividualはHP0でdowned、他の分類はshatteredになります。以後の戦闘力集約と対象から外れます。実HP損失合計の25%を切り上げて士気を減らします。指揮官が戦闘不能なら生存者の指揮寄与が高い順、同値ならID順で継承し、士気をさらに10減らします。生存者がなければ敗北です。

敗北部隊は移動・攻撃できず、行動値も回復しません。Party、Unit、配置、元の位置を敗北記録として保持し、盤上の占有・駒描画から外します。そのHexへ進入・通過・新部隊作成ができ、生存部隊との同座標保存も可能です。生存者の休養・HP回復と、HP0の記録を残した部隊離脱は新規対局で利用できます。撤退、復活、捕虜、戦利品は未実装です。[休養と離脱](recovery.md)。「AIとの遭遇戦」は敵が通常遠隔・近接攻撃を選び、全活動部隊撃破で決着します。[勝利条件](victory.md)。

部隊の補充・合流・分割後は移動・攻撃・割り込みをそのターン終了します。HPと護衛容量は回復しません。通常の近接反撃と肩代わりは既存の規則で可能です。分割で別部隊になった護衛・対象の指示だけを解除します。[部隊の再編](parties.md)。

## 都市への攻撃

新規都市争奪戦の都市耐久は100、城壁は最大60です。近接は隣接、遠隔は各Unitの射程で攻城し、城壁から先に損害を与えます。攻城後は行動と割り込みを終了します。新規対局の都市は攻城後も防御が残れば近接攻城に全体ターン1回反撃します。遠隔と破城時には反撃しません。攻城側は残る反応で割り込めますが、応酬後に行動・反応を終了します。肩代わり・装甲・士気・指揮継承・敗北は部隊戦闘と共通です。予測に都市反撃の有無と自軍HP損失を表示します。旧攻城版1には反撃を追加しません。駐屯部隊への通常攻撃とは別の行動です。両HP0にして中心へ進入し、占領Commandで所有権を変えます。[都市](cities.md)・[城壁](../buildings/walls.md)・[詳細](../../doc/CITY_SIEGE.md)。

休養中の部隊に正のHP被害が入ると休養を中止します。肩代わりで同行者だけが傷ついた場合も中止し、被害のない射撃失敗では予約を維持します。新規対局の王国軍事力は、HP0になったUnitを数加算から外します。Unit記録自体は保持します。
