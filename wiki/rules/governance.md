# 軍事力・統治力・負荷

[Wiki入口](../README.md) · [リソース一覧](../resources/README.md)

軍事力は王国の軍事基盤、統治力は組織や領土を管理する能力、負荷は管理対象の大きさを表す指標です。

現在: 簡略式による算出・表示を実装しています。軍事力をそのまま戦闘ダメージへ使う処理や、統治力不足による罰則はありません。

## 現在の軍事力

次を合計します。

| 要素 | 加算値 |
| --- | --- |
| 王国の科学進捗 | 5ごとに1。端数切り捨て |
| 所属都市の生産産出 | そのまま合計 |
| Gold備蓄 | 25ごとに1。端数切り捨て |
| mana備蓄 | 5ごとに1。端数切り捨て |
| 軍事人員 | 人員値×2 |
| 王国の生存非民間ユニット数 | 数×4（新規対局。HP>0・活動中。開拓者は除外） |

新規対局は生存Unitだけを数え、戦闘でのHP0直後に再計算します。[戦闘不能者の離脱](recovery.md)で二重に減算しません。Unitの登録一覧は履歴として維持します。休養版のない旧保存では、従来のHP0を含む登録非民間Unit数を使います。戦場で使うパーティー戦闘力は、別途[戦闘](./combat.md)の式で求めます。

## 現在の統治力と負荷

| 指標 | 合計する要素 |
| --- | --- |
| 統治力 | 王国文化進捗を5で割った整数部分 + 制度値×3 + 統治人員×2 + 建物数 |
| 統治負荷 | 所有タイル数 + 都市数×2 + 総都市人口 + 建物数 |

制度値の初期値は1、統治人員の初期値は1です。現在の統治力には[宗教](../resources/religion.md)産出を入れていません。制度を選択する画面もありません。

開始直後の暁都では統治力5・負荷11ですが、この超過による産出減少、反乱、命令拒否などは起きません。現段階の値は運営の実効上限ではありません。

## 予定

軍事力には兵站・装備・人員運用などを接続する方針です。統治力には宗教、文化、制度、統治施設や人材を反映し、負荷には区画・パーティー・占領地・未統合人口なども含めます。

統治余力が不足した場合、維持費上昇、産出低下、補給悪化、離反・反乱などを段階的に発生させる設計です。最終的な係数・猶予・段階は未確定で、現行の簡略式を完成仕様とはしていません。
