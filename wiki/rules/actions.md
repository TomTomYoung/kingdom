# 行動一覧

[Wiki入口](../README.md) · [ターン](./turns.md) · [パーティー](./parties.md)

都市の生産・購入と、パーティーの移動・攻撃は別の行動です。全員へ共通の「一ターン一行動」を割り当てる仕組みではありません。

## 画面から行える操作

| 操作 | 対象 | 消費・進行 |
| --- | --- | --- |
| 生産対象を選ぶ | 都市 | 次の開始処理から生産が進む |
| 戦士・弓兵・弩砲・開拓者・建物を購入 | 都市 | 全額のGold。即時完成 |
| 領土を購入 | 王国領に隣接する未所有Hex | 対象ごとのGold |
| パーティーを編成 | 選択セルの未編成ユニットを1〜5体指定 | 現行では資源・移動力を消費しない |
| 待機兵を補充 | 同じセルの待機Unitと選択部隊 | 関係部隊の移動・攻撃・反応を0、行動終了 |
| 合流・分割 | 隣接部隊／一部のUnitと隣接セル | 地形費を検証し、関係する全部隊の行動・反応を終了 |
| 休養 | 新規対局の生存負傷者がいる部隊 | 未使用の行動・反応を終了。次の全体ターン開始にHP回復 |
| 戦闘不能者の離脱 | 新規対局の生存者とHP0が混在する部隊 | 未使用の行動・反応を終了。HP0の記録を残して枠を空ける |
| 配置変更 | 選択パーティーの3×3枠 | 空き枠へ移動・Unit同士の交換。消費なし |
| 都市占領 | 都市争奪戦の敵都市中心にいる軍事部隊 | 攻撃回数1以上。移動・攻撃・反応を0、行動終了 |
| 攻撃 | 敵パーティー・その配置内の照準 | 通常・狙い撃ち・範囲・貫通。攻撃1、移動力0、行動終了。予測後に確定 |
| 護衛設定 | 同じ部隊の別ユニット | 設定は消費なし。肩代わりは容量、割り込みは反応1 |
| パーティーを選択 | マップ上のパーティー | 消費なし |
| 経路移動 | 選択パーティー | 通過セルの地形費合計。現在の移動力以内 |
| ターン終了 | 現在の手番 | 次の手番・ターンへ進む |
| セーブ・ロード | ゲーム全体 | ブラウザ内へ保存・復元 |
| 新規開始 | ゲーム全体 | 現在のプレイ状態を固定seedの初期状態へ戻す |

開拓者を含む部隊では都市建設欄も表示します。移動力1以上、未所有の非虚無地、既存都市から4ヘクス以上などの条件を満たす現在地で建設し、開拓者1体を消費します。同行部隊は行動終了し、新都市は人口1、次のターン開始から収入を得ます。[開拓者の条件](../units/settler.md)。

## 移動と攻撃の回数

現在のパーティーは最大移動力2、攻撃回数1です。[平原・草原・霊脈](../terrain/README.md)は進入コスト1、森林・丘陵は2、虚無は進入不可です。入るための移動力が不足する場合は移動できません。

通常移動は他の生存パーティーがいるタイルを経路に含められません。現在は所有国による国境通行の制限、道路・河川・支配領域の補正はありません。

移動後にも条件を満たせば攻撃できます。現行の攻撃判定は残り移動力を必須条件にせず、攻撃後は移動力0・行動終了になります。攻撃回数が構成員数に増えることはありません。

## 予定されている行動

| 分類 | 予定内容 |
| --- | --- |
| 民間建設 | 労働者の改善建設・修理 |
| 戦術 | 略奪、防御態勢、待機、スキップ、スリープ |
| 育成 | 個人・パーティーの昇進、ユニットのアップグレード |
| 能力 | スキル・魔法・探索・罠解除・説得など |
| 組織 | パーティー解散、指揮官変更、任意離脱 |
| 遠征 | ダンジョン進入・帰還・補給 |

これらは現在選べるコマンドではありません。建設チャージなどの有限回数は、毎ターン回復する移動力と分ける設計です。

左クリックはセル・Unitの確認です。移動先を選び「ここへ移動」を押すか、移動先を右クリックすると経路移動します。購入はセル詳細のボタンで実行します。選択解除はボタン・Esc・ロードで行い、新規開始では初期部隊を選択します。地図では到達可能セルと経路を表示します。ドラッグ・矢印キー・全体図で表示範囲を移動し、＋/−またはホイールで整数倍率に拡大できます。音声は初期オフで、音声ボタンと音量スライダーから設定できます。音声ファイルを読み込めない場合は内蔵の音符データで再生し、「音声を再読み込み」で取得から再試行できます。敗北したパーティーは移動できません。記録を保持して盤上占有を解除するため、その位置へ移動・通過・新部隊作成ができます。[STATUS](../../doc/STATUS.md) を参照してください。

「AIとの遭遇戦」はターン終了後にAIが移動・攻撃・手番終了を行います。AI手番中と対局終了後は行動ボタンを停止し、地図・ログの確認と保存は利用できます。結果と再開は[勝利条件](victory.md)・[ターン](turns.md)を参照してください。

「AIとの増援戦」は兵の生産設定・Gold購入・待機兵の編成も共通の行動規則で行います。購入はGold予備費24を残し、各都市1ターン1回までです。生存兵と生産予約が計15体以上なら新規発注を止め、最大5体ずつ編成します。同じセルの待機兵を既存部隊へ補充し、即時攻撃がなければ小部隊同士を合流します。再編で行動・反応を終了します。AIの自動分割はなく、数値は暫定です。[詳しい判断順](../../doc/AI_SCENARIOS.md)。

「AIとの都市争奪戦」は都市占領も共通Commandで実行します。軍事部隊が敵都市中心に入り、未終了・攻撃回数1以上で「都市占領」を押すと確定します。移動だけでは所有権を変えません。[都市占領](cities.md)・[勝利条件](victory.md)。

新規都市争奪戦では「攻城と都市占領」から近接／遠隔の都市攻撃を実行できます。攻城は攻撃回数を使い部隊行動と割り込みを終了します。両防御HPが0の中心へ入ってから、別途「都市を占領」で確定します。[都市耐久と城壁](cities.md)。

新規都市争奪戦の近接攻城では、都市防御が残る場合に都市反撃を受けます。都市ごとに全体ターン1回、遠隔攻城・破城時は反撃なしです。自軍のHP損失予測と残る都市反撃回数を確認できます。[都市反撃](../../doc/CITY_RETALIATION.md)。

[休養・戦闘不能者の離脱](recovery.md)は新規対局の全モードで利用できます。敵軍隣接・敵領・移動攻撃後は実行できず、休養は被害や敵接近で中止します。AIも合法な離脱とHP50%以下の休養を選びます。旧保存には追加しません。

2026-10-31: 新規対局の[王国研究](research.md)で対象選択・切替・一時停止と施設解禁を利用できます。科学の配分は全都市収集後の全体ターン開始だけです。研究はParty行動を消費せず、途中進捗を保存します。
