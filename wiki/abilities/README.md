# 能力一覧

[Wiki入口](../README.md) · [能力と状態](../rules/abilities.md)

現在使える能動能力は戦士の[治癒](heal.md)、弓兵の[魔弾](arcane-bolt.md)・[魔力波](arcane-wave.md)です。新規のAI増援戦・都市争奪戦で使用できます。治癒は同じ部隊の味方を回復し、魔弾は射程2の敵Unitへ抵抗で軽減する魔法被害を与えます。魔力波は同じ横列の敵Unitへ範囲被害を与えます。旧版1は治癒のみ、旧版2は治癒と魔弾を維持します。mana・移動力・攻撃回数・有限チャージを消費します。正式な職業・スキル・呪文一覧は未確定です。
