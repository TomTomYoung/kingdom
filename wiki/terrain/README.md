# 地形一覧

[Wiki入口](../README.md) · [領土の取得](../rules/territory.md) · [リソース一覧](../resources/README.md)

地上マップを構成する6種類の地形です。地形の種類は現在、各タイルに一つだけ設定されます。森林が草原へ別レイヤーで重なるといった組み合わせはありません。

## 地形ごとの産出と移動

| 地形 | 食料 | 生産 | Gold | 科学 | mana | 宗教 | 文化 | 進入コスト |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| [平原](./plains.md) | 1 | 2 | 0 | 0 | 0 | 0 | 0 | 1 |
| [草原](./grassland.md) | 2 | 1 | 0 | 0 | 0 | 0 | 0 | 1 |
| [森林](./forest.md) | 1 | 2 | 0 | 0 | 0 | 0 | 1 | 2 |
| [丘陵](./hills.md) | 0 | 3 | 1 | 0 | 0 | 0 | 0 | 2 |
| [霊脈](./arcane.md) | 1 | 0 | 0 | 1 | 2 | 1 | 0 | 1 |
| [虚無](./void.md) | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 進入不可 |

産出は「市民がそのタイルで働く場合」の毎ターン値です。都市の基礎産出と建物の効果は別に加算します。虚無を除く所有タイルから人口分を自動選択するため、欲しい産出の地形を領有しても必ず働くとは限りません。

進入コストは移動先の地形で決まり、現在のパーティー最大移動力は2です。他のパーティーがいるタイルへは移動できません。道路、河川、視界、支配領域による移動補正は未実装です。

通常のマップは半径3の37Hexです。固定seedから生成され、外周には虚無が現れる場合があります。海洋・山岳・砂漠などの別種類は現行定義にありません。
