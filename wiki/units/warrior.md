# 戦士

[ユニット一覧](./README.md) · [Wiki入口](../README.md)

![戦士](../../assets/graphics/unit-warrior/v001/image.png)

初期段階の軍事ユニットです。王国の都市で生産・購入し、パーティーへ編成して運用します。分類は一人の冒険者ではなく部隊（Detachment）です。

現在: 生産・購入・編成・移動が画面から可能です。近接攻撃・護衛設定も画面から利用できます。識別子は `warrior` です。

## 費用と入手

| 項目 | 値 |
| --- | --- |
| 生産費 | 生産12 |
| 即時購入 | Gold 48 |
| 解禁条件 | 技術・建物などの前提条件なし |
| 出現位置 | 生産・購入した都市の中心 |
| 初期所属 | 王国所属、パーティー未編成 |

## 基本能力

| 能力 | 値 | 現在の扱い |
| --- | ---: | --- |
| 最大HP | 100 | 被害で減少。0で戦闘不能 |
| 近接戦闘力 | 20 | パーティーの近接戦闘力へ寄与 |
| 遠隔戦闘力 | 0 | 遠隔能力を持つ種類として定義されていません |
| 魔法戦闘力 | 0 | 魔法攻撃そのものが未実装 |
| 防御力 | 18 | 防御側パーティーの戦闘力へ寄与 |
| 装甲 | 2 | このユニットへの被害を2減らす。最低被害1 |
| 抵抗 | 5 | 値はありますが、被害軽減には未接続 |
| 射程 | 1 | 遠隔戦闘力0のため射撃能力にはなりません |
| 命中率・回避率 | 100%・0% | 通常近接は必ず命中。狙い撃ちを受ける際に回避率を使用 |
| 挑発・遮蔽 | 15%・25% | 新規戦士。通常対象の誘導と狙い撃ちの命中率に影響 |
| Guard率・Guard容量 | 50％・50 | 新規作成する戦士。装甲前の肩代わり量を容量から消費 |
| 護衛範囲 | 縦横距離1 | 同じ部隊の別Unitを護衛可能 |
| 士気寄与 | 10 | 値はありますが、士気集約には未接続 |
| 指揮寄与 | 5 | 指揮官継承時の優先順位に使用 |
| 個別移動力 | 2 | 現行のパーティー移動力は別途固定2 |
| 忠誠 | 100 | 初期値。忠誠変動は未実装 |
| 個別人心維持費 | 0 | 個別費用の王国合計への反映は未実装 |

既存セーブで率0・容量0の戦士は値を保持します。命中・回避・挑発・遮蔽がない旧セーブでは100%・0%・0%・0%を補完し、挑発や遮蔽を追加で強化しません。新規作成した戦士から上記の護衛能力を持ちます。割り込みは容量を使わず、部隊の反応1を消費します。

## 運用

同じ都市中心にいる未編成の戦士を最大5ユニットまでまとめられます。人数が増えても、現行のパーティー攻撃回数は1のままです。同じ能力の戦士を増やしても戦闘力が人数倍にはならず、現在は生存構成員の平均値を使います。

HPが0になると戦士は `shattered` となり、通常の戦闘対象・戦闘力集約から外れます。回復、補充、昇格、装備変更は未実装です。

遠隔戦闘力が0のため、戦士だけのパーティーは射撃できません。射程1の値だけでは遠隔攻撃能力を持ちません。K-03の不具合は修正済みです。
