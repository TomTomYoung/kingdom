# 弩砲

[ユニット一覧](./README.md) · [Wiki入口](../README.md)

射程3の兵器（Construct）です。識別子は `ballista`。都市で生産・購入でき、「遠隔部隊の二国対戦」では各国に1体が編成されています。画面では「弩」のバッジを使います。専用画像・射撃音は未制作です。

## 砲撃

通常遠隔に加え、指定縦列への「縦列砲撃」「貫通射撃」、指定枠を中心とする「十字砲撃」を使えます。射程が届く、生存した弩砲だけが専用攻撃の戦闘力へ寄与します。

| 攻撃 | 範囲と倍率 |
| --- | --- |
| 縦列砲撃 | 左・中央・右の指定縦列。生存Unitそれぞれへ65% |
| 十字砲撃 | 中心枠と縦横に隣接する枠。生存Unitそれぞれへ50% |
| 貫通射撃 | 指定縦列を前から走査。生存対象の1体目100%、2体目60%、3体目36% |

空枠と戦闘不能Unitは貫通の深さに数えません。各対象への配分を小数点以下切り捨てし、0なら被害を与えません。余剰被害を別の対象へ繰り越さず、攻撃中に倒れたUnitの奥へ範囲を広げません。範囲の主対象への護衛は1回だけ発動します。
