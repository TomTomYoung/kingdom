# Kingdom Wiki

王国を育て、パーティーを編成し、領土とダンジョンへ進むためのゲーム事典です。資源の使い道、ユニットの能力、地形の産出、都市の成長や戦闘の仕組みを項目ごとに調べられます。

## 現在遊べる範囲

都市の生産・購入、領土拡張、パーティー作成・選択・移動、ターン終了と保存が利用できます。戦闘と配置変更の処理はありますが、画面から操作する機能はありません。区画、研究対象の選択、NPC加入、ダンジョン、勝利判定は未実装です。

各項目の「現在」は確認時点の挙動、「予定」は設計がある未実装部分を指します。個別名や数値が未定のものは、未定と記載します。Civilization VIの施設・技術・数値をそのままKingdomの内容として補ってはいません。

図版にはAIPaintで制作した初回素材を使っています。Wikiへの掲載はゲーム画面への素材接続を意味しません。[素材プレビュー](../doc/ASSET_PREVIEW.md) も参照できます。

確認日: 2026-09-13。参照したmainは [636c222](https://github.com/TomTomYoung/kingdom/commit/636c222634927ec2fe54dd1b5e33d1950c31861e)、ゲームコードの基準はe0dcb3f、ルール版はm1.0です。今後の変更に合わせて項目を更新します。

開発上の既知課題は [STATUS](../doc/STATUS.md)、実装詳細は [CURRENT_IMPLEMENTATION](../doc/CURRENT_IMPLEMENTATION.md)、Wikiの更新方法は [EDITING](./EDITING.md) にあります。
