## 現在遊べる範囲

都市の生産・購入、領土拡張、同じ王国の都市切替と都市別の領土・市民作業、指定Unitによるパーティー作成・待機兵補充・合流・分割・選択・3×3配置編集・経路移動、セル/Unit詳細、ターン終了と保存が利用できます。二国交互操作、敵選択・予測・攻撃、護衛設定、戦闘ログも利用できます。弓兵・弩砲の購入生産と、7定義の通常・狙い撃ち・範囲・貫通を試せる遠隔二国対戦も利用できます。「二都市運営」で暁都と東都を切り替え、都市別の収集内訳・生産・食料・文化を確認できます。「AIとの遭遇戦」では敵が自動で移動・攻撃し、部隊撃破の勝敗または40ターンの引き分けまで遊べます。「AIとの増援戦」では敵が兵の生産・購入・編成・補充・合流も行い、直近の手番の行動回数を確認できます。「AIとの都市争奪戦」では城壁と耐久を削り、敵都市へ進入して占領し、全都市の支配で勝敗を決めます。部隊全滅だけなら都市から再建できます。新規対局では近接攻城への都市反撃と、AIによる脅威下の城壁建設もあります。全モードの新規対局では部隊の休養によるHP回復と、戦闘不能者の記録を残した離脱も使えます。新規版3では城壁都市から敵部隊への能動砲撃も利用できます。区画、研究対象の選択、NPC加入、ダンジョン、Domination全体は未実装です。

各項目の「現在」は確認時点の挙動、「予定」は設計がある未実装部分を指します。個別名や数値が未定のものは、未定と記載します。Civilization VIの施設・技術・数値をそのままKingdomの内容として補ってはいません。
