# 区画一覧

[Wiki入口](../README.md) · [都市](../rules/cities.md) · [建物一覧](../buildings/README.md) · [地形一覧](../terrain/README.md)

区画（District）は、都市に属する建設対象として計画されている分類です。目標仕様では都市の生産キューで建設し、統治負荷にも関わります。

現在: 実装済みの区画は0種類です。個別の区画名、種類別の効果・費用・解禁条件・配置条件は未定です。区画を選んでHexへ建設する操作はありません。

## 区画と混同しやすいもの

| 対象 | 現在の扱い | 区画との関係 |
| --- | --- | --- |
| 都市中心 | 都市の位置として存在。「城」の文字で表示 | 現時点では建設可能なDistrictとして定義されていません |
| [モニュメント](../buildings/monument.md) | 都市に所属する建物。文化+2 | 独立したHexを占める区画ではありません |
| [平原・森林など](../terrain/README.md) | マップを構成する地形 | 建設する施設ではありません |
| [領土](../rules/territory.md) | 王国が所有するHex | 購入・文化拡張だけでは区画や建物は作られません |
| タイル改善 | 労働者の行動として計画 | 区画とは別の建設系統で、現行では未実装です |

## 決まっている方針

区画はユニット・建物と同じく都市生産の対象にする方針です。Goldで購入できるかは対象定義によって決め、すべての区画が購入可能とは限りません。労働者の改善建設、開拓者の都市建設とは別の処理になります。

区画を追加する際は名称、役割、産出・効果、生産費、購入可否、解禁条件、配置条件、統治負荷を個別項目へ記録します。隣接ボーナスや人口による建設上限などは、現時点でKingdomの確定ルールとして数値化されていません。
